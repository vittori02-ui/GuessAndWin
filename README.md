# **GuessAndWin**
this is a game that is almost like 'betting' on the colored number generated by the PC, in fact if the number is the same type, like even or odd, and the color is different you get 5, only the color 2, and if everything is correct 10 points
Download instructions: Go to the itch link and download the .jar file and you can run immediatily. The language used is Java using the NetBeans IDE
The inspiration for this project came when my little cousin told me about a game they played at school with their classmates, and i wanted to recreate it and let him try it out.
